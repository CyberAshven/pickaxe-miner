# Legacy engine by CyberAshven

Historical source reference, licensed under Pickaxe Miner's AGPL-3.0-only license:

- `cuda/`: native CUDA sources from Pickaxe commit `59c93c1`.
- `rust/`: independent Rust engine sources from Pickaxe commit `353d1f9`.

This archive is not compiled by the miner and is not a standalone build. Use those Git revisions for complete historical build environments. Active legacy paths remain available with `--no-default-features --features incremental-k`; the default selects the pinned upstream-derived Rust CUDA backend.
